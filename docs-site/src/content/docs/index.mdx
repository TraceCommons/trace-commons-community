## The rule that applies everywhere

Raw session files stay on the contributor's machine. A client parses and redacts locally, applies the contributor's consent scope, and submits a versioned envelope. The server validates and re-scrubs every envelope before accepting it into the register or holding it for review.

:::tip[You stay in control]
Submission is opt-in. Use a dry run or preview before the first upload, inspect what will leave the machine, and withdraw contributed traces later.
:::
